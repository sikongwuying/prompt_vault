## 基础要求

请帮我生成一个新的程序，需要遵循以下要求：

### 安全合规要求

- 严格遵循security.md文件中的所有安全检查清单
### 技术实现要求

1. **CloudFormation模板**：提供完整的基础设施即代码模板
    
2. **安全最佳实践**：
	- 所有API调用使用HTTPS
	- 实现适当的身份验证和授权
	- 数据传输和存储加密
	- 输入验证和输出编码
	- 访问控制和权限管理

3. **监控和日志**：集成CloudWatch和CloudTrail
    
4. **部署文档**：提供详细的部署和配置说明
    

### 程序功能需求

- 生成安全周报，自动推送到订阅的邮箱中；
- 周报的数据来源是从一个已有的dynamodb数据库中获取的，通过appsync写入和读取。获取创建时间为最近1天的所有新闻。
	- type: dynamodb
	- region: <region-code>
	- table name: [your-database-name](your-database-endpoint)
	- appsync queries example:
```
query MyQuery {
  listCompliances(
    filter: {createdAt: {gt: "2025-08-20T00:04:53.756Z", lt: "2025-08-21T00:04:53.756Z"}}
  ) {
    nextToken
    items {
      createdAt
      id
      introduction
      source_url
      title
    }
  }
}


```
- 通过SES发送邮件
- 邮件模板采用html的格式，顶部大标题是“每日安全合规新闻-xxxx年xx月xx日”，湖水蓝渐变背景，文字白色；卡片的设计为主体白色背景，边框深蓝色，标题字体黑色，18像素，加粗；发布时间黑底白色字体，10像素；正文仅显示“简要描述”，深蓝色字体，12像素；信息来源，8像素。
- 需要包含以下信息，新闻可能会很多个，因此需要通过卡片的方式展现很长段的内容，一个卡片一个信息块包含以下信息：
	- title，也就是标题
	- createdAt，发布时间
	- introduction，正文
	- source_url，信息来源
